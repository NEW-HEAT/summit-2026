# Authorship opening

Glowing routes across the Cyclades introduce the film, then dissolve into the geographic rewind.

![Routes across the Cyclades](preview.png)

| Part | Source |
| --- | --- |
| Map and routes | [Cyclades scene](cyclades-deck-scene.mjs) |
| Composition and transition | [Browser scene](render.html) |
| Frame capture and encoding | [Renderer](render.mjs), [launch script](render.sh) |

`NH.gif` is the flame input used by the renderer. These files all contribute to the opening.

After root dependency setup, run `bash opening/render.sh --smoke`. The original `cyclades-world-imagery.jpg` is also required; that supplier image was not recovered during archival, so a fresh render remains unverified.
